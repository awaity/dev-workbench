# 开发工作台

## 目标与边界

独立的 Chrome / Edge Manifest V3 扩展，点击图标显示今日待办弹窗，底部入口直接新建完整工作台标签页；交付 ZIP 和解压目录。参考 cookie-workbench：Vue 3、Vite 8、TypeScript、Element Plus、SCSS、pnpm，沿用 ESLint / Stylelint / Prettier，公开 API 使用中文 JSDoc。

全部设置、工具草稿、操作历史（包括二维码 Logo）存入 IndexedDB，不使用服务器或 localStorage。仅 HTTP / WebSocket 工具在用户主动操作时连接目标地址。脚本、图标和字体不依赖远程资源。

## 功能验收

- HTTP：方法、URL、查询参数、请求头、鉴权、请求体、超时、取消、状态/耗时/响应头/响应体、历史重放。
- WebSocket：地址、子协议、连接/断开、发送/接收、日志、历史与恢复。
- SM4：CBC / ECB、PKCS#7 / 无填充、UTF-8 / Hex 密钥与 IV、Hex / Base64 密文。
- SM2：密钥生成、C1C3C2 / C1C2C3、加解密。
- MD5：大小写、16 / 32 位摘要、校验、本地字典与数字范围匹配，可取消。说明摘要不可逆。
- Base64：UTF-8 编解码、URL-safe；SHA：SHA1 / 224 / 256 / 384 / 512 和 HMAC。
- RSA：PEM 密钥生成、PKCS#1 v1.5 / OAEP、加解密。
- AES / DES / Triple DES：CBC / ECB、严格密钥/IV/填充校验、Hex / Base64 密文。
- JWT：Header / Payload / 签名解码、时间声明、可选 HS256 签名验证。
- Bcrypt：哈希、校验、工作因子；URL：组件 / 整体 URL 编解码。
- JSON 在线解析：校验、格式化、压缩、转义/反转义、文件导入导出、树视图。
- JSON 编辑器：代码编辑、树节点增删改、语法错误、保存草稿。
- JSONPath：常用路径与过滤表达式、结果与匹配路径，遵循 MV3 CSP。
- 二维码：文本/网址、尺寸、纠错、配色、模块/定位点样式、Logo 上传移除、PNG / SVG 下载、本地历史。
- 全局设置：主题、默认工具、JSON 缩进、HTTP 超时、二维码默认尺寸、历史/草稿开关、保留数量、收藏、备份导入导出、删除历史/全部数据。

## 视觉设计

配色：纸白 #ffffff、工作区灰 #f4f6fa、墨蓝 #243149、文字灰 #66758c、工具蓝 #365fc7、状态绿 #25796d。深色模式采用同一语义色体系。

字体：界面使用系统中文无衬线（PingFang SC / Microsoft YaHei），代码使用 SFMono-Regular / Consolas。标题 24px、正文 14px、工具与状态 12px。离线优先，不下载字体。

结构：左对齐的工具索引，中央可操作编辑面板，右侧可收起的历史。重点放在代码与结果，不使用宣传性大卡片。新版深蓝底白色 W 图标与蓝色导航选中状态形成统一识别，图标从同一 SVG 生成。

```text
工具导航       | 面包屑 / 本地状态 / 设置
搜索           | 工具标题与用途             | 本地历史
开发           | 参数 / 操作工具条          | 条目
JSON           | 输入编辑器 | 结果 / 树视图 | 条目
加密与编码     |            |               |
二维码         | 字符数 / 状态              |
设置           |                            |
```

审查：本项目是高频开发工具而非仪表盘；去掉欢迎页、统计卡片和装饰性渐变，默认进入 JSON 编辑区。移动端导航折叠，历史为可关闭区域，所有表单保留明确标签、键盘焦点和错误反馈。

## 1.2 自动清理

- 数据管理增加 Element Plus 开关与天数输入，默认开启、保留 30 天，可关闭并保留自定义天数。
- 清理超过期限的历史和孤立附件，保护草稿、集合及仍被引用的文件；与历史数量上限同时生效。
- 在同一 IndexedDB 事务中删除过期历史、检查引用和删除附件，失败时整体回滚；后台逐条检查引用以控制内存占用。
- 后台每日闹钟、浏览器启动、工作台打开、设置保存、备份导入均应用最新规则；关闭工作台也可执行每日清理。
- 验证严格时间边界、关闭开关、旧设置/备份兼容、事务回滚及真实 Chrome 闹钟事件，发布为 1.2.0 ZIP。
