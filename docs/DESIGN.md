参考 Todoist 中文站展示的任务列表：把日期、勾选与任务文字作为视觉中心。浏览器入口采用与 Cookie 工作台相同的 action popup，独立页面避免加载代码编辑器和加密工具。

## 实施前设计计划

- 产品：本地开发工作台，日常操作应清楚、紧凑、安静。
- 图标：深蓝 `#233F78` 圆角方形承托白色几何 W。W 对应 Workbench，两处折点呈现连续的工作流；不增加文字、小装饰或复杂渐变。
- 形状：64 × 64 网格，14 px 圆角，6 px 线宽，主体居中并保留清楚的外侧留白。
- 应用：同一 SVG 用于侧栏与 favicon，resvg 生成 16 / 32 / 48 / 128 / 256 / 512 PNG；manifest 与工具栏复用这些资源。
- 界面：保留浅灰工作区、白色内容区、蓝色主操作；深色模式使用既有语义色。请求与响应分区，参数、鉴权、变量归入页签。
- 组件：按钮、表单、对话框、标签、上传等使用 Element Plus。代码编辑器使用 CodeMirror，键值表与文件字段为组合组件。组件内部渲染的原生 DOM 属于库的正常实现。
- 字体与空间：沿用本地系统中文字体；正文 13–14 px、辅助 11–12 px，主要间距 8 / 16 / 24 px。不依赖在线字体和外部图片。

## 设计自审与验收要求

- W 的两处低点应在 16 px 下仍可区分，四边留白一致；图标必须检查实际 PNG，不能只看放大 SVG。
- 保留表单控件的可访问名称、键盘焦点与禁用状态；文件选择通过 ElUpload。
- 窄屏中请求方法、URL 和发送按钮可换行，参数的名称和值可见，不能把整个工作台撑出屏幕。
- 真正图片响应仅允许常用位图预览；HTML 与 SVG 保持文本查看，避免响应内容成为页面活动代码。
- 最终截图与测试结果记录在 VERIFICATION.md；此文件的设计目标不代表验证已通过。
